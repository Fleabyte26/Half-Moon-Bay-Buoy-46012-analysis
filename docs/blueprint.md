# **App Name**: OceanCast AI

## Core Features:

- Personalized Wave Forecasts: Users can select a specific ocean location to view current and upcoming wave height, period, direction, meteorological conditions (wind), and tide tables relevant to that area.
- Historical Data Explorer: Visualize trends and historical patterns of wave data, buoy readings, and other environmental factors over the past 40 years for selected locations.
- Forecast Breakdown Tool: A generative AI tool that explains, in natural language, how the confluence of buoy data, bathymetrics, meteorological conditions, and tide tables contributes to a specific wave forecast.
- Optimal Conditions Advisor Tool: A generative AI tool that recommends the best times and locations within the forecast period based on user-defined preferences (e.g., 'calm sailing', 'beginner surfing conditions'), analyzing all available data.
- Location Management: Allow users to save their preferred locations for quick access to forecasts and data.

## Style Guidelines:

- Color scheme: Dark. Primary color: Deep Cerulean Blue (#2672D9), evoking the deep ocean and digital precision. Background color: A desaturated dark blue-gray (#15191E) for a sleek, immersive backdrop. Accent color: A vibrant Amethyst Purple (#844DFF), used sparingly for highlights and interactive elements, providing a strong contrast.
- Headline and body font: 'Inter', a clean, modern sans-serif chosen for its excellent readability and versatility across various data presentations, reflecting a focus on clarity and information delivery.
- Minimalist and precise iconography, using clean line art to represent waves, buoys, wind, and tidal symbols, ensuring clarity without visual clutter in data-heavy displays.
- Information-dense layout featuring clearly segmented sections for forecast data, maps, and historical charts. Emphasize a responsive grid system that prioritizes legibility and scannability, with generous spacing to avoid overwhelming the user.
- Subtle, fluid animations for transitions between data views and location selections. Micro-interactions like loading indicators and data point highlights should be smooth and unobtrusive, enhancing user experience without distracting from the core information.
